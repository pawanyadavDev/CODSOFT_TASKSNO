# ExpenseTracker

A frontend-only personal expense tracker (HTML, CSS, JavaScript, Bootstrap 5). Data is saved in your browser's Local Storage.

## Run locally
1. Keep `index.html`, `style.css`, `script.js` in one folder.
2. Double-click `index.html` to open it in a browser (internet needed once for Bootstrap CDN), or run `python -m http.server` in the folder and visit http://localhost:8000.

## Notes
- Local Storage is browser-specific and not secure cloud storage. Clearing browser data erases transactions.
- Nothing is sent to any server.
