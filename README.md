### Task 2: [ TaskBoard -TO-DO LIST APPLICATION ] 
- Description: Taskboard is a task management web application that helps users organize their daily activities. It is built with plain HTML, CSS and JavaScript, with no frameworks or backend, and it runs entirely in the browser.
Users can add, edit, delete and complete tasks. New tasks are validated, so the title must be at least 3 characters and the due date can’t be in the past. Each task has a category, a priority level (low, medium or high) and an optional due date, and overdue tasks are highlighted. A live summary shows the total, pending and completed counts, along with a progress bar.
- Technologies: HTML5, CSS3 (custom properties, Grid, Flexbox), JavaScript (ES6+), Local Storage API
- Features: User-friendly interface and responsive layout.

### Task 3: [ ExpenseTracker ]
- Description: A responsive personal finance dashboard that shows where your money goes. Users add, edit and delete income and expenses, filter by category and type, and see total income, total expenses and balance in Indian Rupees. It also gives spending-by-category bars, automatic financial insights, form validation and a dark/light theme. Everything is saved in Local Storage, so it persists after a refresh.
- Technologies:HTML, CSS, JavaScript, Bootstrap 5, Local Storage
- Features: Interactive functionality and modern UI.

### Task 4: [ Music Player Web music player ]
- Description: A modern web music player built on the HTML5 Audio API. It has play/pause, next/previous, a seekable progress bar, volume and mute with +/− buttons, and a live time display. It also includes a playlist, queue, search, favorites, recently played songs, shuffle, repeat modes and autoplay, with keyboard shortcuts. Settings are remembered between visits.
- Technologies:HTML5 Audio API, CSS, JavaScript, Bootstrap 5, Local Storage
- Features: User-friendly interface and responsive layout.
### Task 5: [ The Daily Notes-Blog webpage ]
- Description:A responsive, editorial-style blog with 12 sample articles. Visitors can search, filter by category or tag, and load more articles. Each article page has a readable layout, social sharing, comments saved in the browser and related-article suggestions. It also has a newsletter form and a dark/light theme.
- Technologies: HTML, CSS, JavaScript, Bootstrap 5, hash routing, Local Storage
- Features: User-friendly interface and responsive layout.
